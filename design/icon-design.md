## 二、字形推导：为什么 Σ 容易画成 Z

这是本次设计里唯一的技术陷阱，单独记下来。

Σ 与 Z 都由 4 个折点、3 段线构成，**区别只在右端两个折点的 x 是否相同**：

```
Z ：  左上 ──→ 右上
                    ╲
                     ╲
      左下 ←──────────╲        上臂在左、下臂在右 → 两条横臂错开
      左下 ──────────→ 右下

Σ ：  左上 ──────────→ 右上   ┐
                    ╱        │ 右端两点同 x
                   ╱         │ → 右边自然形成一段竖边
      左下 ──────→ 右下       ┘   这才是 Σ
```

结论：**斜边下折点的 x 必须明显偏左**。实测（见 `_sigma-test.html`）：

| 斜边偏移 | 读出来的字 |
| --- | --- |
| `diagOffset = 0` | Z（错） |
| `diagOffset = -4` | Z / Σ 之间，勉强 |
| `diagOffset = -6` | **Σ（推荐）** |
| `diagOffset = -9` | Σ，偏陡 |
| `-13`（斜边近垂直） | 退化成「⊐ + 两横」 |

## 三、定稿几何（可直接抄进 VectorDrawable）

### 3.1 环（沿用 Livolog，两个数字都不改）

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 圆心 | `(54, 54)` | |
| 环外半径 `R_OUT` | `22` | 外径 44 |
| 环线宽 | `4.67` | 与 Livolog 完全一致 |
| 环中线半径 `R_MID` | `19.665` | `= 22 − 4.67/2` |
| 缺口位置 | 12 点两侧**各 60°**（共 120°） | 沿用 Livolog |
| 端头 | 圆头，半径 `2.335` | `= 线宽 ÷ 2` |
| 缺口处的独立圆点 | **取消** | Livolog 的它用来补位，Σ 不需要 |

弧的 path（与 Livolog 同构，只是把起点角度换了）：

```
M 63.832,44.168 A 19.665,19.665 0 1 1 44.168,44.168
```

### 3.2 Σ（在环内，居中）

| 参数 | 值 |
| --- | --- |
| 半宽 `halfW` | `8.5` → 总宽 17 |
| 半高 `halfH` | `11` → 总高 22 |
| 线宽 | `4.2`（略细于环，避免抢视觉） |

4 个折点：

| 折点 | 坐标 |
| --- | --- |
| 左上 | `(45.5, 43)` |
| 右上 | `(62.5, 43)` |
| 左下（斜边下折点） | `(48, 65)` |
| 右下 | `(62.5, 65)` |

path：

```
M 45.5,43 L 62.5,43 L 48,65 L 62.5,65
```

斜边倾角 `atan(14 / 22) ≈ 32°`（相对水平）—— 落在「看得出是 Σ 且不呆板」的区间。

## 四、组内关系

| 项 | Livolog | Scholarius |
| --- | --- | --- |
| 主体 | 时钟（圆环 + 指针） | **Σ** |
| 环 | 缺口 12 点起逆时针 300° | 缺口 12 点两侧各 60°（共 120°） |
| 缺口处 | 补一个独立圆点 | 不补 |
| sweep 渐变 | 3 点起顺时针，白在 12 点 | **完全相同** |
| 品牌黑 | `#1B1B1B` | 相同 |
| 笔画线宽 | `4.67` | 环用 `4.67`，Σ 用 `4.2` |

并排看：同一套黑、同一套渐变、同一套线宽与圆头，只有中心符号不同。
