两端各一条**无渐变**短线段，线宽 = 字形线宽 4.67，**两端圆头**。

| 位置 | 起点（尖端） | 终点（内端） | 长度 | 颜色 |
|---|---|---|---|---|
| 头部 | `(70.665, 37.335)` | `(70.665, 46.000)` | 8.333 | `#FFFFFF` |
| 尾部 | `(70.665, 70.665)` | `(70.665, 62.000)` | 8.333 | `#6E6E6E` |

- 尖端在**原端点** `(1,1)` / `(1,-1)`，沿竖直方向**向字形内侧**延伸 `0.5h = 8.333`
- 圆头使外缘恰好达 `73.000` / `35.000`，**正好等于外接框边缘，不撑大**
- 尾部线段落在截断缺口外侧，与截断面间隙 = 线宽 4.67

## 六、实现要点（Android VectorDrawable）

1. **字形 + 短线分 3 条 path**
   - 主体：`strokeColor` = 渐变（sweep 或按需），`strokeWidth="4.67"`，`strokeLineCap="round"`
   - 头/尾短线：各自 `strokeColor` 为**纯色**（`#FFFFFF` / `#6E6E6E`），`strokeWidth="4.67"`，`strokeLineCap="round"`

2. **`type="sweep"` 的语义**（从 Livolog 抄来的关键事实）
   Android 的 sweep 渐变**没有起点角度参数**，固定从 **3 点方向**起、顺时针，
   `offset 0→1` 对应 `0°→360°`。需要「沿路径弧长」的渐变须自行拆 path 或改用其他手段。

3. **不要用 `stroke` 描边字体轮廓**
   字符轮廓是填充图形，描边会把内侧轮廓也画出来 → 黑腔 → 字形塌掉。

4. **端点短线不要用圆点代替**
   短线是胶囊形（矩形 + 两端半圆），不是圆点。
