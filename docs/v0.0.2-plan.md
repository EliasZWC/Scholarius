## 一、导航结构改动

v0.0.1 是「启动页 → 应用内（三标签）」。v0.0.2 插入登录页：

```
冷启动
  └─ 原生启动页（已禁：透明图标）
      └─ 网页 splash 动画（2.2s）
          └─ 检查本地 token
              ├─ 有 token → 应用内（Library / Ranking / Profile）
              └─ 无 token → 登录页（强制，无跳过）
                  └─ Device Flow 成功 → 写 token → 应用内
```

**强制登录已确认**：登录页**不提供**「稍后再说」。

**token 有效期**：首次登录后长期记住（GitHub Device Flow token 默认不过期），只有手动退出登录才回登录页。

## 三、登录页（Device Flow）

### 3.1 流程

```
① 点「Sign in with GitHub」
② 原生 POST https://github.com/login/device/code  (client_id + scope)
   ← 拿到 device_code / user_code / verification_uri / interval
③ 页面大字显示 8 位 user_code，并有「复制」按钮
④ 原生用 Intent 打开 verification_uri（浏览器或 GitHub App 会接管）
⑤ 页面开始按 interval 轮询 POST /login/oauth/access_token
   ← authorization_pending 就继续等；慢下来要按返回的 interval 调整
⑥ 拿到 access_token → 存进 EncryptedSharedPreferences → 进应用
```

### 3.2 硬约束（已核实）

| 项 | 值 |
|---|---|
| Scope | `repo read:user` |
| `client_secret` | **不需要**（Device Flow 的设计目的） |
| 轮询间隔 | 首次 5s；遇 `slow_down` 加 5s |
| 授权码有效期 | 900s |
| 必须的 HTTP 头 | `Accept: application/json`，否则返回 form-urlencoded |

### 3.3 token 存储

用 `EncryptedSharedPreferences`（`androidx.security:security-crypto`）落盘，**不**放 localStorage。
